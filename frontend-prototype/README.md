# Campus Meet FE Prototype

「学内イベント予約管理システム」の画面実装案をもとにした、ブラウザーだけで動くFEのたたき台です。

## 表示

このフォルダーで次を実行し、ブラウザーから `http://localhost:8000` を開きます。

```sh
python3 -m http.server 8000
```

## 実装範囲

- 学生: イベント一覧、キーワード検索、カテゴリ絞り込み、詳細、予約完了、予約一覧、キャンセル確認
- 教員: イベント一覧、イベント作成、参加者一覧
- イベントと予約はブラウザーの `localStorage` に保存するデモデータです。認証、API、サーバー側の予約制御は未接続です。

# Java要件定義

[Notion原本](https://app.notion.com/p/8fc333876e7483b0a79e815249bc4ca4)

## 課題の目的
チームで1つのシステムを企画し、実装に入る前に「誰のどの課題を解決するのか」「何を作るのか」「どう確かめるのか」を整理します。要件を画面、データ、API、クラス、テストへつなげ、チーム全員が設計の理由を説明できる状態を目指す。
要件定義では、機能を並べるだけでなく、背景、利用者、成功条件、品質、制約、対象外の範囲も決めます。「使いやすい」「速い」「安全」といった曖昧な表現は、条件や数値、範囲など、後から確認できる形に具体化してください。決めた要件には識別用のIDを付け、設計とテストから参照できるようにする。

### 選択テーマ
**: 学内イベント予約管理システム**
学生が学内イベントを検索して内容を確認し、参加予約できるシステムです。教職員や管理者は、イベント情報や参加者を管理します。
